Website Guide

Using Little Alexandria is simple. Follow these steps to explore the website.

  1. Go to the Libraries page.
  2. Look through the library listings.
  3. Read the location and library information.
  4. Open the library's official website for updated details.
  5. Check opening hours and visitor rules before going.

Before You Visit a Library

  • Check the library's opening hours.
  • Look up its address and directions.
  • Check if visitors need an ID or registration.
  • Follow the library's rules and keep the space quiet.
